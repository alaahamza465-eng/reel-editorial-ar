# reel-editorial-ar — سكيل لـClaude بيمنتج فيديوهاتك العربية بستايل «Editorial Grain»

بتبعت لـClaude فيديو بتحكي فيه للكاميرا (من الجوال)، وبيرجعلك ريل 9:16 جاهز للنشر:

- **مونتاج:** بيشيل السكتات الطويلة وبيخلي النَّفَس الطبيعي.
- **ألوان:** بيصحّح فيديو الآيفون HDR وبيعطيه تدريج دافي.
- **كابشن عربي:** شريط ورق، والكلمة اللي بتنحكى بتنوّر بالأحمر.
- **كاميرا بتتحرك:** قطع زوم وسحبات سريعة طول الفيديو.
- **تلوين للقصة:** ذكرى (بني)، حرب (رمادي)، هدوء (دافي).
- **شي بيتحرك كل ~3 ثواني:** مجسمات ثري دي على الكلام (مفتاح، عملات، عدسة، مايك، ظرف، بنايات، صندوق كنز، طيارة ورق، كرة أرضية)، وعناصر صغيرة (ملاحظة ورق، فقاعة، رسمة بتنرسم…).
- **لحظات كبيرة:** قائمة، اقتباس بصفحة مجلة، صح وغلط، شطب فكرة غلط، أبواب بتنفتح، ناس بيصيروا ذهب، ومشهد خريطة بيغوص من الكرة الأرضية لمدينة بتطلع.

كل شي كود (FFmpeg + faster-whisper + HyperFrames + Three.js)، بدون أفتر إفكتس ولا برامج مونتاج.

> **الدليل الكامل خطوة بخطوة (PDF):** `guide-ar.pdf` — التثبيت، أول فيديو، نصائح التصوير، جمل تعديل جاهزة، وحل المشاكل.

## التثبيت

### Claude Code (الأفضل)
انسخ مجلد `reel-editorial-ar` لـ:
- ماك/لينكس: `~/.claude/skills/reel-editorial-ar/`
- ويندوز: `%USERPROFILE%\.claude\skills\reel-editorial-ar\`

بدّك على جهازك: **FFmpeg**، **Node 22+**، **Python 3.10+**. أول مرة Claude بيشغّل `scripts/setup.sh` وبيثبّت الباقي.

### تطبيق Claude (claude.ai / الديسكتوب)
1. نزّل ملف السكيل: **[reel-editorial-ar.zip](https://github.com/alaahamza465-eng/reel-editorial-ar/releases/latest/download/reel-editorial-ar.zip)** (من قسم Releases، مش من زر Code، لأنه هداك بيغيّر اسم المجلد).
2. فعّل «Code execution and file creation» من الإعدادات.
3. روح على **Customize > Skills** ← زر **+** ← **Create skill** ← **Upload a skill**.
4. ارفع ملف `reel-editorial-ar.zip` زي ما هو، بدون ما تفكّه.

> الرندر تقيل (ثري دي + فيديو 1080×1920)، فبيشتغل أحسن بـClaude Code أو Cowork على جهازك. بيئة المتصفح ممكن ما يكفيها الوقت أو الذاكرة لفيديو طويل.

## الاستعمال
ابعت الفيديو واكتب مثلاً:
> منتج هالفيديو بستايل Editorial Grain

Claude بيمشي معك خطوة خطوة، وبيوقف مرتين:
1. بيعرض عليك **السكربت** لتصحّح الكلام.
2. بيعرض عليك **ورقة لقطات** قبل الرندر النهائي.

الوقت: التفريغ دقايق، والرندر تقريباً 15-30 دقيقة لكل دقيقة فيديو على جهاز عادي.

## الخط
الستايل الأصلي على **خط ثمانية**، بس رخصته ما بتسمح بتوزيعه، فما بييجي مع السكيل. بدونه السكيل بيستعمل **IBM Plex Sans Arabic + Amiri** (مفتوحين). لو بدك ثمانية: شوف `references/fonts.md`.
