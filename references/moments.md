# moments.json — كل الحقول

```json
{
  "theme": {"paper": "#efe8dc", "ink": "#1a1a1a", "red": "#c2412d"},
  "strike": ["كلمة"],
  "endHold": 1.9,
  "face": [540, 560],
  "camera": "auto",
  "grades": [{"t": 11.6, "look": "memory"}, {"t": 17.4, "look": "war"}, {"t": 24.2, "look": "normal"}],
  "sweeps": [8.85, 66.4],
  "shakes": [57.27],
  "moments": [ ... ],
  "objects": [ ... ],
  "accents": [ ... ],
  "sfx": [{"name": "chime", "t": 12.3, "vol": 0.3}]
}
```
- كل الأوقات بالثواني **على الفيديو بعد القص** (`ns` بـ`words.json`، أو الرقم اللي بيطبعه `script.py align`).
- `theme` اختياري. `strike`: كلمات بالكابشن بتنشطب بخط أحمر لحظة ما تنقال. `endHold`: كم ثانية كرت النهاية بيضل بعد الفيديو. `sfx`: أصوات زيادة (`tick`, `pop`, `snap`, `switch`, `star`, `chime`, `fill`, `counter`, `success`) — معظم الأصوات بتنضاف تلقائياً.
- كل عنصر نصي = `{"text": "...", "t": ثانية_ظهوره}`.

## الطبقات العامة
| المفتاح | ايش بيعمل |
|---|---|
| `face` | `[x, y]` مكان الوجه بالكادر (1080×1920). الكاميرا بتقرّب عليه. الافتراضي `[540, 560]`. |
| `camera` | `"auto"` (الافتراضي): حركة على بداية جملة كل ~2-3 ث بنمط ثابت (قطع زوم، دفعة، سحبة بغباش)، وطبيعية جوا الشرائط والصفحات. أو قائمة يدوية `[[ثانية, "cut"\|"ease"\|"whip"\|"slow", تكبير, x, y], ...]` مثل `[[0, "cut", 1.0, 540, 520], [2.6, "ease", 1.1, 540, 480], [6.7, "whip", 1.0, 540, 560]]`. |
| `grades` | تلوين بيتغير مع القصة: `memory` (بني، ذكرى)، `war` (رمادي)، `calm` (دافي ومنوّر)، `normal`. كل واحد بيضل لحد اللي بعده. `dur` اختياري (0.5). |
| `sweeps` | أوقات لمعة ضو بتقطع الشاشة (1.1 ث). 2-3 بالفيديو. |
| `shakes` | أوقات رجّة خفيفة للكادر. مرة وحدة على أقوى ضربة. |

## أوضاع الكاميرا (تلقائية حسب النوع)
| الوضع | الأنواع | شكله | الكابشن |
|---|---|---|---|
| **band** | `list`, `ledger`, `people`, `doors`, `share` | الفيديو بينزل 560 بكسل لتحت، والرسمة بالشريط فوق (y 170-540) | مخفي (الرسمة هي الكلام) |
| **page** | `quote`, `strike`, `stack` (لحد ما تبدأ `map`) | الفيديو بيصغر لصورة ملصوقة بشريط لاصق (y 746-1464)، والنص فوق على ورق | مخفي |
| **map** | `stack.map` | مشهد ثري دي كامل (كرة أرضية ← مدينة) | مخفي |
| **full** | `card`, `chapter`, `punch` | الفيديو ملء الشاشة | ظاهر |

لحظتين من نفس الوضع ورا بعض بدون فراغ (t1 الأولى = t0 الثانية) بيضلوا بنفس الوضع بدون ما الكاميرا ترجع.

## `punch` — زوم سريع على الوجه
```json
{"type": "punch", "t": 0.55, "until": 3.9}
```
`until` اختياري (يرجع الزوم). بينضاف لحركة الكاميرا. استعمله للهوك ولجملة واحدة قوية.

## `chapter` — شارة فصل صغيرة فوق
```json
{"type": "chapter", "t0": 11.6, "t1": 15.5, "n": "01", "text": "أول مشروع", "side": "right"}
```
فوق y=176. `side`: `right` أو `left` (اختار الجهة اللي فيها حيط مش راس). اختياري — في ناس ما بتحبه، اسأل.

## `list` — قائمة بلاطات (band)
```json
{"type": "list", "t0": 24.2, "t1": 30.6,
 "small": {"text": "جرّبت كل اشي", "t": 24.4},
 "title": {"text": "دوّرت على زباين", "t": 25.1},
 "items": [{"text": "انستقرام", "t": 26.04}, {"text": "واتساب", "t": 26.64}, {"text": "معارف", "t": 27.2}],
 "stamp": {"text": "ولا زبون", "t": 29.24}}
```
- `items`: 2-4 بلاطات. `icon`: `right`/`left`/`up`/`down` (سهم) أو بدون. كل بلاطة بتطلع على كلمتها مع نقرة.
- `stamp` اختياري: ختم أحمر مايل فوق البلاطات (النتيجة)، والبلاطات بتبهت، ورجّة خفيفة.

## `quote` — اقتباس بصفحة مجلة (page)
```json
{"type": "quote", "t0": 39.9, "t1": 45.5,
 "label": {"text": "نصيحة أبوي", "t": 40.2},
 "lines": [
   {"words": [{"text": "اشتغل", "t": 41.16}, {"text": "بهدوء", "t": 41.9}], "size": 116, "weight": "bold"},
   {"text": "مش علشان الناس،", "t": 42.42, "size": 80, "weight": "regular"},
   {"text": "علشان", "t": 43.15, "size": 80, "weight": "regular", "mark": {"text": "حالك", "t": 43.58}}],
 "note": {"text": "حتى لو ما حدا شاف", "t": 44.35}}
```
- سطر فيه `words` = كلمة كلمة بتوقيتها. سطر فيه `text` = بيطلع مرة وحدة.
- `mark`: كلمة بآخر السطر على شريط أحمر بينرسم من اليمين.
- 3 أسطر بالكثير (المساحة لحد y≈700). السطر الأول 100-120، الباقي 70-84.

## `ledger` — صح وغلط (band)
```json
{"type": "ledger", "t0": 49.3, "t1": 55.0,
 "label": {"text": "قاعدة وحدة", "t": 49.5},
 "rows": [
   {"mark": "ok", "big": {"text": "التعب", "t": 52.22}, "small": {"text": "عليك", "t": 51.2}},
   {"mark": "no", "big": {"text": "الكمال", "t": 53.02}, "small": {"text": "مش شرط", "t": 53.5}}]}
```
صفّين بالكثير. `ok` = دائرة حبر وصح، `no` = دائرة حمرا وإكس. الكلمة الكبيرة قصيرة (كلمة أو كلمتين).

## `people` — ناس ثري دي (band)
```json
{"type": "people", "t0": 59.0, "t1": 64.3,
 "small": {"text": "كم واحد بلّش معي", "t": 59.1},
 "big": {"text": "وقفوا", "t": 61.3}, "side": {"text": "من أول شهر", "t": 62.05},
 "then": {"text": "واللي كمّلوا وصلوا", "t": 63.2}}
```
بالشريط فوق: 7 ناس على قاعدة. على `big` بيبهتوا وبيقصروا شوي، وعلى `then` (السطر الأحمر) بيصيروا ذهب وبتنزل عليهم عملات وبيقفزوا. `weak`/`rich` اختياري لو بدك توقيت غير الكلمات. `"crowd": false` بيشيل الناس ويخلي النص بس.

## `strike` — شطب فكرة غلط (page)
```json
{"type": "strike", "t0": 69.3, "t1": 72.5, "ghost": "النجاح",
 "top": {"text": "النجاح", "t": 69.56},
 "neg": {"text": "مش", "t": 69.82},
 "struck": {"text": "بالحظ", "t": 69.94, "strikeAt": 70.3},
 "bottom": {"parts": [{"text": "هو", "t": 71.2}, {"text": "تعب", "t": 71.34}, {"text": "كل يوم", "t": 71.62, "red": true}]}}
```
`ghost` = كلمة ضخمة شفافة 5٪ ورا كل شي (عمق). `strikeAt` = لحظة الخط الأحمر (بعد ما تنقال الكلمة بـ0.3 ث تقريباً).

## `doors` — أبواب بتنفتح (band)
```json
{"type": "doors", "t0": 88.6, "t1": 95.0,
 "small": {"text": "بعد سنة انفتحت", "t": 88.75},
 "open": 89.12,
 "reveal": {"text": "فرص جديدة", "t": 89.72},
 "then": {"t": 91.3,
          "title": {"text": "الشغل الجانبي", "t": 91.62},
          "switch": {"t": 92.3, "off": 93.58},
          "word": {"text": "وقّفته،", "t": 93.58},
          "stamp": {"text": "ما بلحّق", "t": 94.18}}}
```
`open` = لحظة كلمة «فتح» أو ما يعادلها. `then` اختياري: مرحلة ثانية بنفس الشريط (عنوان + زر بيتسكّر + كلمة + ختم صغير).

## `card` — كرت صغير (full)
```json
{"type": "card", "t0": 100.75, "t1": 103.6, "title": "اسم الشركة", "sub": "example.com", "subLtr": true, "y": 1090}
```
للاسم والموقع والحساب. `subLtr` للروابط والأرقام الإنجليزية. خلّي `y` فوق الكابشن (≤1150).

## `stack` — سلسلة ثم مشهد خريطة (page ← map)
```json
{"type": "stack", "t0": 107.8, "t1": 116.55, "ghost": "الحلم",
 "a": {"label": {"text": "وقلت لحالي:", "t": 107.95},
       "lines": [{"text": "بدي", "t": 108.1, "size": 114},
                 {"text": "مشروع صغير", "t": 108.66, "size": 114, "wipe": true},
                 {"text": "بيكبر", "t": 110.3, "size": 86, "red": true, "wipe": true}]},
 "map": {"t0": 111.6, "dive": 113.38, "t1": 116.55,
         "label": {"text": "تخيّل مشروعك بكل", "t": 111.72},
         "chips": [{"text": "الدنيا", "t": 112.84}, {"text": "المدن", "t": 113.36}, {"text": "البيوت", "t": 114.04}],
         "lines": [{"text": "ليش لا؟", "t": 114.88}, {"text": "بس ابدأ.", "t": 115.6}]}}
```
- `a` بيطلع على صفحة مجلة. `wipe` = السطر بينكشف من اليمين.
- `map`: على `t0` الشاشة كلها بتصير كرة أرضية بتلف (قارات مرسومة، مش خريطة بلد حقيقي)، الكاميرا بتغوص فيها لحد `dive` (حطه على الكلمة اللي بتنزل فيها لتحت، زي «المدن» أو «الأرض»)، وبعدها مدينة بتطلع: مباني، دبابيس حمرا (`dive`+0.22)، وأكوام عملات بتطير (`dive`+0.67 — أو `money`). `chips` شرائح حبر بتطلع على الكلمات، و`lines` السؤال بالأحمر. الخريطة بدها 4-5 ثواني على الأقل.
- بدون `map`: ممكن `swap` + `b` (شرائح وأسطر على نفس الصفحة).

## `share` — ابعته لصديقك (band)
```json
{"type": "share", "t0": 116.6, "t1": 118.95,
 "title": {"text": "ابعت هذا الفيديو", "t": 116.76},
 "red": {"text": "لصديقك", "t": 117.48},
 "small": {"text": "اللي بدّه يبلّش", "t": 117.98},
 "plane": 117.55}
```
`plane` = لحظة طيارة ورق ثري دي بتقطع الشريط من اليمين لليسار (اختياري).

## `end` — كرت النهاية
```json
{"type": "end", "t0": 122.7, "ghost": "ابدأ",
 "lines": [{"text": "ابدأ صغير", "t": 122.85}, {"text": "بس ابدأ", "t": 123.25, "red": true}]}
```
بيبدأ على آخر كلمة تقريباً، الفيديو بيتلاشى، وبيضل `endHold` ثانية. الأسطر من كلامه (الخلاصة)، مش شعار جديد.

## `objects` — مجسمات ثري دي فوق الفيديو
```json
{"kind": "coins", "t0": 14.3, "t1": 15.65}
```
كل مجسم بيطلع بنطّة على `t0` وبيختفي على `t1` (1-2.5 ث). `x`,`y` (بكسل الشاشة) و`scale` اختيارية — الافتراضيات مجرّبة وبعيدة عن الوجه.

| `kind` | شكله وحركته | حقول زيادة |
|---|---|---|
| `key` | مفتاح ذهب بينزلق من اليمين ويلف (810,1165) | — |
| `coins` | 5 عملات ذهب بتنفجر من نقطة (540,1230) | — |
| `lens` | عدسة مكبّرة: `sweep` بتمشي من `from` لـ`to`، أو `"motion": "orbit"` بتلف حوالين (x,y) | `lift`: وقت تطلع فيه لفوق · `fall`: وقت توقع |
| `case` | شنطة شغل جلد بتلف (300,1110) | — |
| `mic` | مايك بودكاست بيتمايل (870,990) | — |
| `envelope` | ظرف: `drop` بينزل من فوق (215,250) وبيطير بالآخر، أو `"motion": "across"` بيقطع الشاشة (y=1130) | — |
| `towers` | 3 بنايات بشبابيك بتطلع (235,1268) | — |
| `chest` | صندوق كنز بينفتح وبيضوي (300,712) | `open`: وقت الفتح |
| `plane` | طيارة ورق بتقطع (y=520) | `dur` |
| `globe` | كرة أرضية صغيرة بتلف وبتوقف فجأة (860,1060) | `stop`: وقت الوقفة (على «وقفت» مثلاً) |

## `accents` — عناصر صغيرة كل ~3 ثواني
```json
{"type": "note", "t0": 75.95, "t1": 77.95, "text": "لو عندك وقت"}
```
| `type` | شكله | حقول |
|---|---|---|
| `bubble` | فقاعة كلام فيها حرف أو كلمة قصيرة بالأحمر (795,250) | `text`, `rot` |
| `pause` | زر إيقاف أحمر (110,270) | — |
| `xmark` | دائرة حمرا فيها ✕ (790,250) | — |
| `note` | ورقة ملصوقة مايلة وتحتها خط أحمر بينرسم (110,172) | `text`, `underlineAt` |
| `rings` | 3 دواير بتتوسع (موجات صوت) حوالين نقطة (860,990) | `t0` بس، `cycles` |
| `phone` | موبايل فيه بوست بيدخل من اليسار وقلب بيطلع | `heart`: وقت القلب |
| `rays` | أشعة ضو من فوق الشمال بتلف ببطء | `t0`, `t1` |
| `wheat` | سنبلة بتنرسم (110,300) | — |
| `crack` | شرخ أبيض بينرسم بسرعة (560,700) + طقة | — |
| `growth` | كرت فيه سهم نمو بينرسم (96,250) | — |
| `steam` | بخار فوق الكوب (760,1040) — بس لو الكوب بالكادر | — |
| `underline` | خط أحمر بينرسم تحت الكابشن (300,1398) | — |
| `footsteps` | 5 خطوات أقدام ورا بعض (860,1150) | `n` |
| `calm` | غبار ضو بيطفو + 3 تموّجات (585,1600) | `ripple`: وقت التموّجات |

كل الأنواع بتقبل `x`, `y`. خلّي العنصر على جنب الوجه، وما تحط عنصرين بنفس الوقت.
